# 台账与归档规范（付款回单 OCR）

> 本文件为 `pay-slip-ledger-ocr` 技能的详细规则参考，供执行时核对。

## 1. 工作区目录约定

工作区 = 脚本 `pay_slip_ledger_scan.py` 所在目录（也可用 `--input/--output/--done` 覆盖）。

```
<工作区>/
├── 扫描付款回单生成台账.py / pay_slip_ledger_scan.py  ← 主脚本
├── 付款回单台账.xlsx           ← 12 列台账（追加式，自动维护合计行）
├── 扫描日志.txt                ← 运行日志（UTF-8，与台账同目录）
├── 输入/                       ← 新回单投放区（PNG/JPG/JPEG）
└── 已完成/                     ← 归档区，按收款人（供应商）分子文件夹
    └── <收款人名称>/            ← 例如「荆州市沙市区昌顺五金经营部(个体工商户)」
```

## 2. 台账结构（12 列）

| # | 列名 | 类型 | 说明 |
|---|------|------|------|
| 1 | 序号 | 必填 | 自动续接（追加式，不覆盖旧数据） |
| 2 | 记账日期 | 可选 | 半截回单缺失时留空 |
| 3 | 付款人名称 | 必填(实质) | OCR 常能读到 |
| 4 | 收款人名称 | **必须项** | 缺失→整行待人工核对 |
| 5 | 收款人账号 | 可选 | 去空格 |
| 6 | 开户行 | 可选 | **取收款方开户行**（回单中「开户行名称」出现两次，取第二个） |
| 7 | 币种 | 可选 | 如 CNY |
| 8 | 金额 | **必须项** | 数字，两位小数，#,##0.00 |
| 9 | 金额大写 | 可选 | 原样保存（壹/贰/叁…） |
| 10 | 摘要 | **必须项** | 如「潜污泵采购预付款」 |
| 11 | 会计流水号 | 可选 | **幂等去重键** |
| 12 | 批次元号 | 可选 | OCR 常识别为「批次号」 |

**字段规则（重要）**：必须项 = 收款人名称 / 金额 / 摘要。缺任一必须项 → 该行各必须格填「待人工核对」、**文件留在输入目录**不归档。可选字段缺失 → 单元格**留空**，不影响入账与归档。

**合计行**：末尾固定一行「合计」+ Decimal 求和金额（浅橙底 FCE4D6 加粗）。追加与合计在同一次读写内完成，避免孤儿行。

## 3. 归档命名

`<收款人名称>_<金额两位小数>_<摘要>[_<记账日期>].png`

- 金额固定两位小数：`13920.00` / `3927.17`（不要用整数，会丢损）
- 记账日期缺失（半截回单）→ 省略日期段
- 非法字符（`\/:*?"<>|` 与空白）替换为 `_`；收款人段截断 40 字符
- 重名自动追加 `_2/_3`（在供应商子目录内判定）
- 目标：`已完成/<收款人名称>/`（按供应商自动建子目录）

示例：
- `保定蓝深环保科技有限公司_13920.00_潜污泵采购预付款_2026-08-11.png`
- `台州大昌过滤材料有限公司_9185.40_滤布采购款.png`（半截，无日期）

## 4. 已知 OCR 变体（正则已兼容，勿当 bug）

1. 金额带全角逗号：`1，398.00` → 清洗 `[,，\s]` 后解析
2. 批次字段识别为「批次号」而非「批次元号」，且数字可能换行 → 正则 `批次(?:元|原)?号`
3. 「开户行名称」在同一张回单出现两次（付款方+收款方）→ 取第二个
4. 金额 OCR 偶发粘连多余点号 → 只保留整数+最多两位小数
5. 中文冒号/括号可能是全角 → 统一 normalize 为半角再匹配

## 5. 半截回单（图片只有回单上半部分）

财务转发的微信截图常被截断，只有「付款人→摘要」区域，缺底部三件套（记账日期/会计流水号/批次元号）。
判定依据：图片尺寸异常扁（如 710×245）且 OCR 文本止于摘要。
处理：必须三项（收款人/金额/摘要）齐全即可正常入账+归档，可选字段留空——**不要**因此留「待补全回单」目录或拦截。

## 6. 重复与去重

- 去重键 = **会计流水号**（不是文件名——同一回单不同文件名会重复投放）
- 已在台账的流水号 → 直接跳过，不重复入账
- 半截单流水号为空 → 无去重保护，靠文件名/人工注意；完整补发后再扫会与半截单产生两条记录，需人工合并

## 7. 供应商名称归一化（人工）

OCR 会产出同一实体的不同名称变体（如「荆州区昌顺五金电器经营部」vs「荆州市沙市区昌顺五金经营部(个体工商户)」）。
合并方法：归档文件移入正式名文件夹并替换收款人段命名 + 台账该行收款人名称同步 + 删除空文件夹（三处同步，防账实不符）。
当前脚本不自动归并别名；如需自动归一化，需维护「别名→正式名」对照表接入脚本。
