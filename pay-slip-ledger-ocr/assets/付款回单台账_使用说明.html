付款回单台账系统 · 使用说明

财务付款回单 PNG → OCR 智能识别 → 自动生成台账 → 按供应商归档
版本 v2.0 更新日期 2026-09-03 适用对象：经办 / 财务人员

一、这个系统能做什么

把财务发来的付款回单图片（微信截图 / PNG），自动识别文字、提取关键信息、写入 Excel 台账，并按供应商分类归档原图。全程无需手工录入，一张图约 20 秒自动完成。

  • 识别字段：12 项（收款人、金额、摘要、日期、流水号、批次号等）
  • 自动入账：追加到台账末尾，表尾自动计算「合计」
  • 按供应商归档：原图重命名后放入 已完成\供应商名称\
  • 防重复：同一张回单重复投放会自动跳过，不会重复入账

二、目录结构（工作区）

<工作区>\
├── 扫描付款回单生成台账.py   ← 主程序（日常只需运行它）
├── 付款回单台账.xlsx          ← 台账成果（Excel，双击可看）
├── 扫描日志.txt               ← 每次运行记录（自动生成）
├── 输入\                      ← 新回单投放区（把图丢这里）
└── 已完成\                    ← 归档区（自动生成）
    └── 供应商名称\…            ← 按收款人分类的子文件夹
使用约定：正常使用时你只需要动两个地方 —— 把新回单放进 输入\，其余（识别、入账、归档）全部自动完成。目录结构不要手动改动。

三、日常怎么用（三步）

放入新回单。财务发来的回单 PNG 全部丢进 <工作区>\输入\ 文件夹（一次可放多张）。
运行程序。打开命令行，执行：
python "<工作区>\扫描付款回单生成台账.py"
程序会逐张识别（每张约 20 秒，多张时请耐心等待），结束后自动完成入账与归档。
查看结果。打开 付款回单台账.xlsx 核对新增行与底部合计；原图已按供应商分好类存放在 已完成\ 下。
想先试跑不落盘？加 --dry-run 参数即可「只预览、不写台账、不移动文件」：python "…\扫描付款回单生成台账.py" --dry-run

四、运行参数（可选）

参数作用默认值
--input <目录>指定回单图片所在目录…\转账回单\输入
--output <xlsx>指定台账输出路径…\转账回单\付款回单台账.xlsx
--done <目录>指定归档目录…\转账回单\已完成
--ocr-script <ps1>指定本地 OCR 引擎脚本路径本地 NPU OCR run.ps1
--dry-run试运行模式：只预览结果，不写台账、不移动文件关闭
--limit N只处理前 N 张（测试用）0（全部）

绝大多数情况直接双击运行或使用默认命令即可，无需带任何参数。

五、台账字段说明

#列名性质说明
1序号自动按入账顺序自动编号
2记账日期可选回单底部的记账日期；缺失时留空，不影响入账
3付款人名称可选通常为付款单位
4收款人名称必须即供应商，缺此项该单不归档
5收款人账号可选数字，自动去掉空格
6开户行可选取收款方开户行（回单出现两次开户行时自动取第二个）
7币种可选通常为 CNY
8金额必须数字金额（自动兼容千分位、全角逗号等格式），右对齐保留两位小数
9金额大写可选人民币大写原样保留
10摘要必须付款事由（如“潜污泵采购预付款”），缺此项该单不归档
11会计流水号可选同时是去重依据：同一流水号只入账一次
12批次元号可选银行批次信息
字段规则（重要）：只有 收款人名称、金额、摘要 三项是入账必需的（这三项齐全即正常入账并归档）；其余均为可选项，缺失时单元格留空，不影响使用。
只有当三项必需字段中任一项识别失败时，该单才会被标记「待人工核对」并留在输入目录，等待人工检查。

六、归档与命名规则

识别成功的回单，原图会按以下规则重命名并移入对应供应商文件夹：

已完成\收款人名称\收款人名称_金额(两位小数)_摘要_记账日期.png

示例：

  • 保定蓝深环保科技有限公司_13920.00_潜污泵采购预付款_2026-08-11.png
  • 台州大昌过滤材料有限公司_9185.40_滤布采购款.png　无日期时省略日期段

几种自动处理：

  • 按供应商分类：自动在 已完成\ 下创建以「收款人名称」命名的子文件夹
  • 重名不覆盖：同一供应商、同金额、同摘要的多笔，自动追加 _2、_3 后缀
  • 日期缺失：半截回单（无底部日期区域）正常入账归档，文件名省略日期段

七、防重复与安全性

机制说明
按流水号去重程序先读台账已有「会计流水号」，识别后比对——同一流水号直接跳过，不会重复入账（即使文件名不同）
可重复运行同一批图跑两遍，第二遍会全部跳过，台账不会翻倍
失败不丢单OCR 失败或必需字段缺失的单据留在 输入\ 目录、不删除原图，处理记录写入 扫描日志.txt
追加不覆盖台账已存在的历史记录不会被覆盖，新单只往后追加
注意：运行期间请勿用 Excel / WPS 打开台账文件（会锁文件导致写入失败）。程序提示失败时，关闭台账后重新运行即可，已入账部分不会重复。

八、常见情况处理

情况系统表现你需要做什么
正常完整回单识别 → 入账 → 重命名归档进供应商文件夹无需操作
半截回单（只有上半部分）收款人/金额/摘要齐全即正常入账，日期等可选字段留空无需操作；如需日期可向财务要完整截图
重复投放同一批图按流水号自动跳过，不重复入账无需操作
必需字段读不出行内标「待人工核对」，原图留在 输入\人工查看原图，修正或重发清晰图片后再跑
供应商名称写法不一如「荆州区昌顺」与「沙市区昌顺」会各建文件夹需要合并时告诉助手，可同步合并台账与归档文件

九、常见问题（FAQ）

Q1：每次跑要多久？

约 20 秒 / 张（本地 CPU 识别）。10 张约 3~4 分钟，耐心等待窗口跑完即可。

Q2：运行窗口一闪而过 / 报错怎么办？

先看 扫描日志.txt 的报错内容；最常见的两个原因：①台账正被 Excel/WPS 打开（关闭后再跑）；②某张图片 OCR 超时（该张会跳过并记入日志，不影响其余）。仍有问题可把日志发给助手排查。

Q3：台账能不能加/减字段？

可以。脚本采用表头驱动设计，加字段只需修改脚本中的表头与提取规则；历史数据追加不受影响。需要改动时告诉助手即可。

Q4：会计流水号缺失的单据还能去重吗？

流水号缺失（如半截回单）时按流水号去重会失效，请勿重复投放同一张图。如希望加强去重，可告诉助手增加「按文件名+金额+摘要」的兜底去重规则。

Q5：归档文件名里的供应商名想要统一的正式名？

可建立「别名 → 正式名称」对照表，让脚本识别时自动归一化（例如把同一家店的多种写法统一为一个名称）。需要时告诉助手配置。

十、运行环境与技术备注

项目说明
